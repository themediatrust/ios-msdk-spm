# Changelog

All notable changes to the iOS MediaFilterSDK Swift Package Manager distribution are recorded
here. The version of this package always matches the version of the XCFramework it ships.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.6.1] - 2026-09-29

First release from this repository.

- `MediaFilterSDK` binary target: the 1.6.1 XCFramework, vendored in the package and referenced
  by a path-based `binaryTarget`. Slices: iOS device, iOS Simulator, Mac Catalyst.
- Release notes for the SDK itself are maintained separately and distributed to publishers.
